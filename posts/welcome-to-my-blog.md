# 안녕하세요!

새로운 블로그에 오신 것을 환영합니다! 이 블로그는 **Next.js**, **TypeScript**, **Tailwind CSS**를 사용하여 만들어졌습니다.

## 블로그의 목적

이 블로그를 통해 다음과 같은 내용을 공유하고자 합니다:

1. **개발 경험** - 프로젝트를 진행하며 배운 것들
2. **기술 튜토리얼** - 유용한 기술과 도구들
3. **일상 이야기** - 개발자로서의 일상

## 기술 스택

이 블로그는 다음과 같은 기술들로 만들어졌습니다:

- **Next.js 15** - Static Site Generation
- **TypeScript** - 타입 안정성
- **Tailwind CSS** - 빠른 스타일링
- **Redux Toolkit** - 상태 관리
- **Zod** - 데이터 검증
- **Markdown** - 포스트 작성

## 주요 기능

### 검색 기능
포스트 제목, 설명, 태그로 검색할 수 있습니다.

### 태그 필터링
관심 있는 태그를 선택하여 관련 포스트만 볼 수 있습니다.

### 반응형 디자인
모바일, 태블릿, 데스크톱 모든 기기에서 최적화된 경험을 제공합니다.
